# VOLTOS 2.1

Особистий застосунок домашньої енергії для iPhone: **BLUETTI EB3A · Oukitel · Atlantic**.

Інтерфейс на TypeScript і Capacitor, нативний Bluetooth, Swift-міст до Keychain, системний Share Sheet. Це **гібридний iOS-застосунок**, не SwiftUI. Встановлюється через Xcode; BLE не потребує сервера. Хмарні інтеграції використовують наявний бекенд VOLTOS.

## Встановлення на iPhone

Потрібні Mac, Xcode, Node.js 22.12+ та iPhone з iOS 15+.

```sh
npm ci
npm run ios
```

Xcode → **App → Signing & Capabilities → Team** → вибрати свій iPhone → **Run (⌘R)**. Якщо потрібно, увімкнути Developer Mode на iPhone. Xcode-проєкт уже в репозиторії: `ios/App/App.xcodeproj`. Не потрібно повторно виконувати `cap add ios`.

[Детальна інструкція та перевірка обладнання](docs/IOS-RELEASE.md).

## Що реалізовано

Оновлення 2.1: [робочі простори пристроїв, стабільний ввід, графітовий дизайн](docs/UPDATE-2.1.md) і [прямий Wi-Fi Oukitel](docs/OUKITEL-LAN.md).

Додатково: швидке LAN-автопідключення без очікування хмари, відновлення після фону/Wi-Fi, прогноз до резерву, власний план навантаження та підтверджувані параметри AC-заряджання/частоти на сумісній Oukitel. Докладно — [автопідключення та прогноз](docs/AUTOCONNECT-FORECAST.md).

- Огляд резерву й потужності, окремі стани Bluetooth / хмарний знімок / застарілі дані / офлайн.
- Стриманий інтерфейс для iPhone: світла, темна й системна теми, нижня навігація, панелі пристроїв, системні відступи, підтвердження дій та підтримка reduced motion.
- EB3A: заряд, роздільні AC/DC вимірювання в адаптері, виходи AC/DC, LED, ECO, таймер ECO, Standard/Silent/Turbo, Power Lifting. Записи обмежені переліком регістрів і перевіряються читанням. Непідтримувані параметри заблоковані.
- Сценарії EB3A «Тиха ніч», «Швидкий заряд», «Економія»: попередній перегляд змін, перевірка кожного кроку, зупинка з описом часткового виконання.
- Oukitel: власний акаунт, вибір станції, актуальний cloud-статус доступності, знімки показників, ручні AC/DC/USB команди із серверною перевіркою належності пристрою.
- Atlantic: авторизація через свій Atlantic Home, температури, живлення, режими. Керування враховує команди, які повернув пристрій.
- Локальна історія окремо за джерелом і пристроєм, до 30 днів / 130 000 записів; перенесення історії версії 1 без приписування невідомій станції.
- Графіки за годину / добу / тиждень з реальною часовою шкалою та прогалинами зв’язку. CSV із реальними рядками, на iPhone — через системне меню «Поділитися».
- Оцінка автономності за вибраним навантаженням, поріг низького заряду, журнал подій без паролів і токенів.
- Нативні сесії в Keychain з доступом лише на цьому пристрої. Паролі не зберігаються. Прострочені сесії очищуються за HTTP 401.

## Перевірки

```sh
npm run check        # TypeScript клієнта і API, production build, unit/integration tests
npx playwright install chromium webkit
npm run test:e2e     # браузерні сценарії на контрольних API-відповідях
npm run test:offline # production-оболонка без мережі після npm run build
npm run ios:sync     # вебзбірка, sync плагінів, дозволи й іконки
```

Браузерні тести використовують **контрольні відповіді**, не надсилають команд на твоє обладнання. У production-коді немає демонстраційної телеметрії.

## Локальна розробка

```sh
npm ci
npm run dev
```

Vite обслуговує інтерфейс. Для локального запуску `/api` потрібен сумісний сервер Vercel та серверні змінні з `.env.example`; сам Vite не виконує serverless API. Сторінка відобразить помилку підключення, якщо API відсутній.

Нативний застосунок за замовчуванням звертається до `https://voltos-belli.vercel.app`. Для власного сервера перед збіркою можна задати **публічний** `VITE_API_BASE=https://your-api.example`. Це лише URL; секрети в `VITE_*` додавати не можна.

## Межі поточної версії

Це приватна збірка, підготовлена до випробування на обладнанні. Компіляція не підтверджує фактичне виконання команди конкретною прошивкою.

- iOS може призупинити Bluetooth та збір даних у фоні. Цілодобовий моніторинг, push, WidgetKit та автоматизації без активного застосунку потребують окремої реалізації.
- Oukitel повертає хмарний знімок без гарантованого часу вимірювання. Cloud readback не є незалежним фізичним підтвердженням.
- Сесія Oukitel діє до 12 годин, Atlantic — до 7 днів. Keychain не подовжує строк дії. Для повторного входу потрібні свої облікові дані.
- Atlantic використовує приватний міст до однієї інсталяції Atlantic Home. Багатокористувацький доступ у цій версії відсутній.
- Енергоісторія, тарифи, MYCOND і серверний збір Atlantic Home не перенесені: чинний міст передає температури та керування, а не ці дані. PWA Atlantic Home залишається доступним окремо.
- Оцінки запасу й автономності залежать від заданої номінальної ємності, не замінюють вимірювання станції.
- Для Safari на iPhone прямий Bluetooth недоступний; потрібна iOS-збірка. Web Bluetooth лишається доступним у сумісних браузерах інших платформ.
